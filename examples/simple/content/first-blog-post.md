# My First Blog Post

Welcome to my new blog! I'm excited to share my thoughts and experiences here.

## Why Archavist?

I chose **Archavist** for several reasons:

1. **Obsidian Integration** - I already write all my notes in Obsidian, so it's natural to use them for blogging
2. **Modern Technology** - Built with [[react-19-features|React 19]] and TypeScript
3. **Simple Workflow** - Write in Obsidian, generate with Archavist, deploy anywhere
4. **Link Graph** - Automatic backlinks make it easy to navigate related content

## My Writing Setup
