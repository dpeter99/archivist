## About This Site

This site demonstrates how Archavist can transform your Obsidian notes into a beautiful static website with:

- **Wiki-style links** - Use `[[page-name]]` syntax to link between pages
- **Frontmatter support** - Add metadata to your pages
- **Backlinks** - Automatically generated backlinks between pages
- **React 19** - Powered by React 19's new prerender API

Check out the [[getting-started|Getting Started]] guide to learn more!
